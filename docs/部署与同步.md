# 版本管理与家用机部署

> 目标：本机改完 → 一条命令推到远程仓库 → 家里机器拉下来就能跑。
> 本文只写这套流程必需的东西。项目结构见 `PROJECT.md`。

## 0. 现状（2026-10-22 已完成的部分）

- 本机 `D:\cs2-qq-bot` 已是 git 仓库，分支 `main`，首个提交 tag `v0.3.25`，102 个文件 / 1.27 MB。
- **不入库**：`config.yaml`（含 token/密钥）、`data/`（数据库 1.8 GB）、`logs/`、`archive/`、`.venv/`、`botpy.log*`。
- 运维脚本已改成**相对路径**，克隆到任意目录都能跑（不再依赖 `D:\cs2-qq-bot`）。

## 1. 建远程仓库（一次性，你自己操作）

**推荐 Gitee 私有库**（国内速度快、免代理）。GitHub 也可以，但推送经常要代理。

1. 打开 gitee.com → 新建仓库 → 名字如 `cs2-qq-bot` → **私有** → **不要**勾选“初始化仓库 / 添加 README / 添加 .gitignore”（勾了会和你本地历史冲突）。
2. 复制仓库地址，在本机项目目录执行（二选一）：

```bat
cd /d D:\cs2-qq-bot

:: HTTPS（第一次推送会要求账号密码，密码位置填“私人令牌”）
git remote add origin https://gitee.com/<你的用户名>/cs2-qq-bot.git

:: 或 SSH（需先在 Gitee 上传本机公钥）
git remote add origin git@gitee.com:<你的用户名>/cs2-qq-bot.git
```

3. 首次推送（带上 tag）：

```bat
git push -u origin main --follow-tags
```

**私人令牌怎么弄**

- Gitee：头像 → 设置 → 私人令牌 → 生成新令牌（勾 `projects` 权限）→ 复制一次，妥善保存。
- GitHub：Settings → Developer settings → Personal access tokens → Fine-grained token（勾仓库 Contents: Read and write）。
- 令牌是密码级别的东西，**不要写进任何入库文件**。用 Windows 凭据管理器保存（首次输入时勾选记住）。

**如果不想用命令行保存令牌**，让 Git 记住：

```bat
git config --global credential.helper manager
```

## 2. 本机日常上传（每次改动后）

```bat
:: 双击即可，或带一句说明
scripts\push.bat
scripts\push.bat fix: 盯盘基准口径迁移不误报
```

脚本会：`git add -A` → 提交 → `git push`。它同时会检查“有没有配置远程仓库”，没配会直接提示，不会半途失败。

**改动纪律（和 `PROJECT.md` 第七节一致）**

1. 改代码 → 升版本号 → 写 `更新日志.md` 置顶条目
2. 跑 `tests\run_all.py` 全绿
3. 重启机器人验证（本机）
4. `scripts\push.bat "vX.Y.Z 一句话"`

## 3. 家里首次部署（新电脑）

假设家里是 Windows。**装两个东西**：

| 软件 | 说明 |
|---|---|
| Git for Windows | https://git-scm.com/download/win ，一路下一步 |
| Python 3.10+ | https://www.python.org/downloads/windows/ ，安装时**务必勾选 Add python.exe to PATH** |

然后：

```bat
:: 1) 克隆（路径随意，D:\cs2-qq-bot 或 C:\Users\你\cs2-qq-bot 都行）
git clone https://gitee.com/<你的用户名>/cs2-qq-bot.git D:\cs2-qq-bot
cd /d D:\cs2-qq-bot

:: 2) 一键初始化：建 venv、装依赖、检查配置、跑自测
scripts\setup_home.bat

:: 3) 首次运行会生成 config.yaml 并停下，让你填 3 个密钥
notepad config.yaml

:: 4) 注册计划任务（开机自启 + 看门狗 + 每日结算）
scripts\register_tasks.bat

:: 5) 启动
scripts\restart_bot_hidden.vbs

:: 6) 看日志
live_log.bat
```

**config.yaml 怎么从本机带到家里**（它不能走 git）：

- 首选：U 盘 / 网盘传这一个文件（里面是 CSQAQ token、QQ AppID/Secret、智谱 key）。
- 或者：照 `config.example.yaml` 手工填一遍（顺便核对新机器的路径类配置）。

**想让家里的关注列表和推送群不丢**：

```bat
:: 本机（准备停用那台）
stop_and_export.bat          :: 生成 data\state_export.json

:: 家里
:: 把 state_export.json 放到 data\ 下
import_and_start.bat
```

## 4. 家里更新（本机又改了代码之后）

```bat
scripts\update_and_restart.bat
```

它做三件事：`git pull --ff-only` → 装依赖（requirements 有变化时）→ 重启机器人。
拉取不是快进（说明家里有本地改动）时**不会重启**，先把改动处理掉再跑。

## 5. ⚠️ 两台机器不要同时跑

- 同一个 QQ AppID 在多处登录会互相顶下线；
- CSQAQ token 的限流是**按 token 共享**的，两边同时跑等于把 10 次/分钟砍半；
- CSQAQ 有 **IP 白名单**，换机器/换网络大概率直接 401（`当前环境IP与账户所绑定的IP不符`）。

正确姿势：**同一时间只让一台在线**。切换时：旧机 `stop_and_export.bat` → 新机 `import_and_start.bat`。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `git push` 报 403 / 认证失败 | 令牌过期或没勾仓库权限 | 重新生成令牌，`git config --global credential.helper manager` 后重试 |
| `pull` 报 `not a fast-forward` | 家里有本地提交/改动 | `git status` 看哪些文件；`git stash` 暂存后 pull，再 `git stash pop` |
| 家里起来全是 401 | 新 IP 不在 CSQAQ 白名单 | 到 CSQAQ 后台把新公网 IP 加进白名单 |
| 家里关注列表是空的 | `data/` 不入库，全新库 | 走第 3 节 `state_export.json` 流程 |
| 家里没有历史行情 | `data/csqaq.db` 1.8 GB 不跟 git | 正常；池子会自动重建，历史可从零积累（如需迁移另说，见下） |
| 计划任务没跑 | 注册时用了别的账户 | 用**当前登录账户**运行 `register_tasks.bat`，任务身份为 Interactive |
| 想改回 `D:\cs2-qq-bot` 之外的目录 | 已全部相对路径 | 直接克隆到新目录即可，无需改任何脚本 |

**要不要把 1.8 GB 的数据库也同步？** 不要用 git。真需要历史行情，用 U 盘拷 `data/csqaq.db`（连同 `-wal` / `-shm` 一起，且**拷之前先停机器人**）。日常没必要——池子和榜单会自己重建。

## 7. 安全清单

- [ ] `config.yaml` 从未出现在 `git log --stat` 里
- [ ] 远程仓库是**私有**的
- [ ] 令牌只存在凭据管理器里，不写进文档/脚本
- [ ] 万一误提交了 key：`git rm --cached config.yaml` → 立即到 CSQAQ / QQ 后台**重置密钥** → 再清理历史

检查命令：

```bat
git log --stat --all | findstr /i "config.yaml data/ logs/"
:: 无输出 = 干净
```
